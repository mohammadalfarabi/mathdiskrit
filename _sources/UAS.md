### a. Closeness Centrality
|  | a | b | c | d | e | f | g |
| - | - | - | - | - | - | - | - |
| g | 3 | 4 | 4 | 3 | 2 | 1 | 0 |

$$
Cc(g) = \frac{7-1}{3+4+4+3+2+1} = 0.3529
$$
### b. Betweenness Centrality
|  | a | b | c | d | e | f | g |
| - | - | - | - | - | - | - | - |
| f | 2 | 4 | 3 | 2 | 1 | 0 | 1 |

$$
C_b(f) = \frac{7-1}{((13-1)(13-2))/2} = 0.3333
$$
